# Maison Valér — Product Image Manifest

Every product-card image is **square 1:1** — recommended **1200 × 1200 px**, **.webp**, sRGB. Put them in **`images/products/`** (overwrite the file of the same name).

**Every colour now has 3 views**, so hover + the thumbnail strip work on all of them:
- **-1** = main / front (default) · **-2** = *hover* image (reveals on mouse-over) · **-3** = extra view (thumbnail).
- Want more than 3? Add `-4`, `-5`… to that colour's list in `build_site.py` → `PRODUCTS`, then run `python3 build_site.py`.

Legend: 🟤 photo = crop of your existing photography · 🎨 placeholder = coloured tile marked "PLACEHOLDER" (replace).
