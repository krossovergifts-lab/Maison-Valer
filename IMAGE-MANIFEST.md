Every filename already exists so the site is fully working now:
- 🟤 **photo** = a cropped crop of your existing photography (looks real).
- 🎨 **placeholder** = a coloured tile marked "PLACEHOLDER" — swap for a real shot.

How the card uses them:
- **-1** = main/front (shown by default) · **-2** = *hover* image (reveals on mouse-over) · **-3+** = thumbnail strip.
- Add more views by continuing the numbering (…-4, …-5) in `build_site.py` → `PRODUCTS`, then run `python3 build_site.py`.
